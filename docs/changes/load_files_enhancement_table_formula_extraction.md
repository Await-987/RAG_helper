# load_files.py 增强表格和公式提取功能

## 修改日期
2026-03-03

## 修改内容

### 1. 增强表格内容提取

#### 修改前
- 表格只提取 `table_caption`（标题）
- 未处理 `table_body`（表格正文）
- 未处理 `table_footnote`（表格脚注）

#### 修改后
- 新增 `extract_table_content()` 函数
- 完整提取表格的三个组成部分：
  - 表格标题 (`table_caption`)
  - 表格正文 (`table_body`)
  - 表格脚注 (`table_footnote`)

### 2. HTML 表格处理

#### 新增功能
- 新增 `parse_html_table()` 函数处理 HTML 格式的表格正文
- 将 HTML 表格转换为易读的文本格式

#### 输出格式
```
表格: 性能对比表
表格内容:
+-------+--------+
| 方法  | 准确率 |
+-------+--------+
| 方法A | 95%    |
| 方法B | 92%    |
+-------+--------+
表格脚注: 数据来源：实验
```

#### 处理特性
- 使用 `BeautifulSoup` 进行精确解析（可选）
- 自动计算列宽，对齐显示
- 添加表头分隔线，保持层次结构
- 降级处理：无 BeautifulSoup 时使用正则解析

### 3. 公式内容提取

#### 保持功能
- 公式从 `text` 字段提取
- 支持 LaTeX 格式公式
- 在 `chunk_types` 中记录公式类型

### 4. 代码改进

#### 主要修改点
1. **type2key 映射保持不变**：确保向后兼容
2. **新增表格内容处理逻辑**：
   ```python
   if chunk_type == 'table':
       content = extract_table_content(data[idx])
       new_chunk += content
   ```
3. **Overlap 部分同步更新**：确保内容一致性
4. **错误处理增强**：
   - HTML 解析失败时返回原内容
   - 无 BeautifulSoup 时降级处理

### 5. 影响范围

#### 影响的函数
- `preprocess()`: 主要修改函数
- `load_and_store_file()`: 调用修改后的预处理

#### 提取内容更完整
- 表格：标题 + 正文 + 脚注
- 公式：LaTeX 格式完整保留
- 其他类型：保持原有逻辑

## 测试建议

1. **表格测试**：
   - 验证 HTML 表格是否正确转换为文本格式
   - 检查表格脚注是否包含
   - 测试跨行/跨列表格的处理

2. **公式测试**：
   - 确保 LaTeX 公式完整保留
   - 验证公式在 chunk 中的标记

3. **混合内容测试**：
   - 测试包含表格、公式、文本的混合内容
   - 验证 chunk 大小和重叠是否正确

## 注意事项

1. 依赖 `BeautifulSoup`（可选，无时使用正则降级）
2. 表格正文是 HTML 格式，无论本地还是远程部署都一致
3. 修改保持向后兼容，不影响原有功能
